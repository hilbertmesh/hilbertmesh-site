◆ ABOUT THIS BUILD

WHAT THIS IS

The Hilbert Dossier Forge (public console) is a local-only structured dossier template generator. It produces the prompt scaffolding, cover identity blocks, 15-section dossier architecture, and specialist mode templates that can be expanded by any AI of your choice.

Local templates run in your browser. Paid Live Forge dossier runs hand off title, theme, seed, constraints, mode, and page count to secure Stripe checkout.

WHAT THIS IS NOT

This console does not contain a backend, vault, account system, session verification, API key storage, viewer simulator, or developer console. It does not authenticate. It does not track. Stripe checkout is the only network call.

HOW TO USE

1. Identity — Set Title, Theme, Iteration, Codename in the Forge tab.
2. Mode — Choose Hilbert / Intelligence / Research / Argue / Critique / Pacer Stress.
3. Style + Presentation — Pick a style guide and presentation mode.
4. Generate — Click Draft Dossier for a free local template, or Build Live Forge Dossier for a paid AI run via Stripe.
5. Expand — Paste local templates into any AI for full multi-page expansion.
6. Trace — Use the Command Center tab to run lineage / timeline / map-thinking analysis on any seed.

FLASHCARD INDEX

The Flashcards tab carries 99 forge-ready seed cards across 19 active lanes — radionics, orgonite, plasma cosmology, ZPE, AGI sentience, anti-gravity, Tartarian, Carr, Schauberger, Winter, classified aerospace analogs, cross-lane master synthesis, and more.

Each card supports four copy operations (Title / Theme / Seed / Pacer), a one-click Load → Forge, both Draft Dossier (free local) and Paid Forge Dossier (Stripe handoff) actions, a Load Into Specialist Mode ▼ dropdown that routes the card into any of the 11 specialist engines, a Send to Command Center action, a Load Into Lineage Mode ▼ dropdown, and a Trace Connections button that produces a local map-thinking output. Constraints auto-derive from card metadata.
