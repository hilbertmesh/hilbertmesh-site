◆ ABOUT THIS BUILD

WHAT THIS IS

The Hilbert Dossier Forge (public shell) is a local-only structured dossier template generator. It produces the prompt scaffolding, cover identity blocks, 15-section dossier architecture, and pacer-compliant 9-page drafts that can be expanded by any AI of your choice.

Local templates run in your browser. Paid Live Forge dossier runs hand off title, theme, seed, constraints, mode, and page count to secure checkout.

WHAT THIS IS NOT

This shell does not contain the full S5 Dossier Forge backend, vault system, account-bound private session, backend AI completion routing, or developer console tools. Those live inside the private S5 system and are not part of this public shell.

This Forge does not store API keys, does not authenticate, and does not verify sessions. Paid Forge checkout uses Stripe handoff only.

HOW TO USE

1. Identity — Set Title, Theme, Iteration, and Codename in the Forge tab.
2. Mode — Choose Hilbert Run, Intelligence Run, or one of the Specialist Modes (Field Experiment, Contradiction Engine, System Design, Pacer Build).
3. Style + Presentation — Pick a style guide (Hilbert OG / Green Hacker / Seed Adaptive / Intel Clean) and a presentation mode.
4. Generate — Build a structured template, send it to the Viewer, validate with the Pacer.
5. Expand — Paste the output into any AI to produce the full multi-page dossier.
