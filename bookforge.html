▸ WHAT CHANGED

This is the corpus engine. No API key. It runs on the S5 forge backend (mode=lore) — the same path Live Forge uses — so the house key, tied to the platform, does the generation. You must be logged into an S5 account. Σ is consumed per chapter as with any Live Forge run.

▸ REFERENCE LIBRARY

A shared shelf, capped at 20MB. Anyone can view and download. Only dev/master can add or remove — the same model as the DJ Booth. Attach library books (or your own private uploads) to any forge run to steer voice and continuity.

▸ ENGINE

OUTLINE — one forge call returns a chapter map. CHAPTERS — one forge call per chapter, each carrying the outline, the prior chapter's tail, and any reference excerpts. STITCH — local assembly with the corpus header and closing notation. Survives reload; resumes from the last finished chapter.
