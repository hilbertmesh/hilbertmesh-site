▸ WHAT THIS INSTRUMENT IS

The Bookforge is a single-page overnight novel engine. Send a seed, choose how long the book should be, press BEGIN FORGE, and walk away. The forge generates an outline first, then writes each chapter in sequence with cross-chapter continuity, then stitches the manuscript with the corpus header and closing notation. The book lands in the Vault.

▸ THE STATIONS

I. THE FORGE — new book from a seed. Up to 1M characters. Outline → chapters → stitch.

II. EXTEND BOOK — continue, branch, or insert into an existing book in the vault. Preserves voice.

III. VAULT — the local library. Cover-style cards. Tier badges. Search and filter. The Viewer opens any book in the 5D recovered-library reading mode — paginated, chromatic-ghost letters, parchment surface, slow scroll. Dev/master accounts can delete; everyone else can only archive.

IV. POSTING — for posting to the public node. Requires the Public Dossier Course + valid corpus header + S5 session. The course is the calibration; the header is the seam. Both must be in place. The instrument enforces both.

▸ ENGINE ARCHITECTURE

Three-phase pipeline:

PHASE 1 — OUTLINE. One call to Claude with the seed and the target chapter count. Returns a structured outline with chapter titles, beats, and a controlled vocabulary list.

PHASE 2 — CHAPTERS. One call per chapter, in sequence. Each call carries the outline, the previous chapter's last ~3000 characters (so continuity holds), and the chapter's own beat list. Failures are retried with exponential backoff. The forge survives reload and resumes from the last completed chapter.

PHASE 3 — STITCH. Final call assembles the corpus header, table of contents, chapters, and closing notation. The Vault receives the finished book.

▸ API & COST

The forge calls api.anthropic.com directly from your browser using the anthropic-dangerous-direct-browser-access header. Your API key is stored only in this device's localStorage and sent only to Anthropic. Cost estimate, live: a 50k-char draft on Sonnet is roughly $0.25; a 1M-char book on Opus is roughly $20-30 depending on chapter complexity. Set spend caps in your Anthropic console for peace of mind.

▸ POSTING RULES

Anyone can write their own version, as long as it follows the corpus. The Public Dossier Course is the gate. The header validator is the second gate. Books that pass both can be posted to the public stream.
